Cara Mendapatkan API Key

  1. Buka situs web Google AI Studio (Klik di sini).
  2. Login menggunakan akun Google (Gmail) Anda.
  3. Di halaman utama, cari dan klik tombol biru bertuliskan "Get API key" atau "Create API key".
  4. Pilih opsi "Create API key in new project".
  5. Tunggu beberapa saat sampai kode kunci API Anda muncul.
  6. Klik Copy pada baris kode API Key tersebut.
  7. Kembali ke aplikasi ini, paste (tempel) kunci tersebut ke kolom Google Gemini API Key, lalu klik tombol "Simpan Pengaturan".
Catatan: API Key Anda bersifat rahasia dan akan disimpan dengan aman di dalam browser perangkat Anda (Local Storage).
